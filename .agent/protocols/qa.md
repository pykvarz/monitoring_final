# QA & Review Protocol

## Базовый QA (всегда перед коммитом)
1. Запусти линтер, проверку типов и тесты — точные команды бери из `memory-bank/techContext.md` → «Команды».
2. Если раздела «Команды» там нет — спроси пользователя и запиши его, прежде чем полагаться на угаданные команды.
3. Все проверки обязаны быть зелёными перед коммитом.

## Adversarial Self-Review (перед коммитом)
Критически изучи свой `git diff`:
- **Граничные случаи:** null/undefined, пустые строки/массивы, сетевые тайм-ауты, дублирующие запросы, гонки.
- **Соответствие стандартам:** см. `standards.md` и `memory-bank/systemPatterns.md`.
- **Производительность:** N+1 запросы, блокирующие синхронные вызовы, утечки памяти, лишние ререндеры.
- **Гигиена:** debug-логи (`console.log`/`print`), неиспользуемые импорты, закомментированный код, временные костыли.

Важно: это самопроверка тем же агентом, который писал код — у неё есть слепые зоны. Она дополняет, но не заменяет реальные тесты, и не заменяет ревью человеком для Full Pipeline задач.

## Loop Breaker (защита от потери данных)
- Не более 3 попыток самостоятельно исправить одну и ту же ошибку.
- Если не получилось: `git restore <только файлы, изменённые тобой в этой сессии>` — никогда `git restore .` (можно удалить ручную работу пользователя).
- Опиши план декомпозиции задачи и жди решения пользователя.

## Дополнительные проверки
- **Visual Web QA** (веб + изменение UI): подними локальный сервер, проверь вёрстку, адаптивность, консоль браузера.
- **Scripts QA** (автоматизации/скрипты): тестовый прогон с mock-данными.

## Definition of Done
- [ ] Тесты и линтер зелёные
- [ ] Adversarial Self-Review пройден
- [ ] `.env.example` обновлён, если появились новые переменные
- [ ] README обновлён, если изменился интерфейс/команды
- [ ] `memory-bank/` обновлена
- [ ] ADR создан, если принималось значимое архитектурное решение (см. `design.md`)
- [ ] `memory-bank/designSystem.md` обновлён, если менялся или добавлялся UI (см. `design.md`)
- [ ] Ветка запушена, PR открыт по `git-workflow.md` — НЕ смержен без разрешения пользователя
