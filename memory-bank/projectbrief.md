# Project Brief — Network Monitor

## Суть проекта
Десктопное Windows-приложение для мониторинга доступности сетевых узлов (хостов) в реальном времени.
Разрабатывается как **внутренний корпоративный инструмент**.

## Для кого
Системные администраторы и ИТ-специалисты, которым нужен простой визуальный контроль доступности хостов без сложной инфраструктуры.

## Ключевые сценарии
1. **Мониторинг**: Периодический ICMP-пинг списка IP/хостов → визуальный статус (Online / Waiting / Offline / Maintenance).
2. **Уведомления**: Системные push-уведомления при переходе узла в Offline.
3. **Управление хостами**: Добавление, редактирование, удаление хостов и групп.
4. **Импорт/Экспорт**: Массовый импорт из Excel, экспорт в Excel.
5. **История**: Журнал смены статусов — когда упал, когда восстановился.
6. **Helpdesk-интеграция**: (опционально) открытие тикета в helpdesk при отказе узла.
7. **Темы**: Светлая и тёмная темы UI.

## Целевая платформа
Windows 10/11. Поставка как .exe (PyInstaller).
