# Design System: Network Monitor

Дизайн-система настольного приложения мониторинга сети на базе PyQt5.

---

## 1. Токены

### 1.1. Статусы узлов (Semantic Status Colors)
Единый источник правды для всех индикаторов, графиков, бейджей и карточек:
- **ONLINE**: `#10b981` (Изумрудно-зеленый) — узел доступен и отвечает на пинг.
- **WAITING**: `#f59e0b` (Теплый янтарный) — временный сбой, ожидание подтверждения.
- **OFFLINE**: `#ef4444` (Рубиново-красный) — узел недоступен, авария.
- **MAINTENANCE**: `#8b5cf6` (Фиолетовый) — регламентные работы / тех. обслуживание.
- **TOTAL**: `#3b82f6` (Синий) — общее количество узлов.

### 1.3. Типографика (Typography)
- **Семейство**:
  - Dark / Light: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Arial, sans-serif`
  - Tactical: `Consolas, "Courier New", monospace`
- **Размеры**:
  - Заголовки разделов / модальных окон: 14–16px, полужирный (bold / 600)
  - Значения метрик в карточках: 24–26px, сверхжирный (black / 900)
  - Основной текст таблицы / списков: 12–13px, нормальный (regular / 400)
  - Вторичный текст, таймстемпы, подсказки: 11–12px, средний (medium / 500)

## 2. Компоненты

### 2.1. Иконки
- **Стандарт**: Строго плоские контурные векторные SVG-иконки в стиле Lucide (`stroke-width="2"`, `stroke-linecap="round"`).
- **Правило**: Запрещено использование цветных системных эмодзи (`📁`, `⚡`, `⚙`, `🗑`, `🟢` и т.д.) в элементах интерфейса, меню, фильтрах и кнопках.

### 2.2. Карточки метрик (Dashboard Cards)
- Подложка с прозрачностью, тонкий нейтральный бордер (`1px solid #282e3d`), радиус скругления 8-10px.
- Акцентный цвет применяется к SVG-иконке и крупному числовому значению, а не в виде кричащей неоновой рамки на всю карточку.

### 2.3. Таблица узлов
- Колонки имеют адаптивное распределение: смысловые колонки («Название», «Адрес») растягиваются, заполняя свободное пространство без черных пустот справа.
- Статус в строке не заливает всю строку тяжелым темным фоном. Используется мягкий оттенок (subtle tint) для сохранения контраста и структуры таблицы.

### 2.4. Боковая панель событий (EventLogPanel)
- Наследует `QFrame` для честной отрисовки границ, скруглений и подложки в Qt.
- Карточки событий имеют акцентную вертикальную полосу слева соответствующего статуса (4px solid), бейдж со временем и именем хоста.
- При отсутствии событий отображается дружелюбный Empty State.

### 2.5. Панель инструментов (Action Toolbar)
- Кнопки сгруппированы по назначению (Действия с узлами | Управление мониторингом | Настройки и экспорт).
- Между логическими группами установлены тонкие вертикальные разделители.
