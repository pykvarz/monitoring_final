# Progress — Network Monitor

## Статус: Активная разработка

## Что реализовано (известно по коду)

### Ядро
- [x] Мониторинг узлов (ICMP ping, параллельный — ThreadPoolExecutor)
- [x] Статус-машина: Online / Waiting / Offline / Maintenance
- [x] Heartbeat throttling (запись last_seen раз в 60 сек)
- [x] Thread-safe обновление UI через сигналы Qt
- [x] Батч-обновления UI (250 мс debounce)

### Хранение данных
- [x] SQLite (PyQt5.QtSql) с WAL-режимом и индексами
- [x] История смены статусов (status_history)
- [x] Очистка истории по сроку хранения
- [x] Миграция из JSON → SQLite (legacy)
- [x] config.json для AppConfig

### UI
- [x] Главное окно с таблицей хостов
- [x] Кнопка паузы мониторинга (с индикатором в статус баре и горячей клавишей Ctrl+Space)
- [x] Современная система всплывающих toast-уведомлений (анимированные карточки в правом нижнем углу)
- [x] Обновлённый дизайн карточек ленты событий (EventCardWidget с цветными акцентами)
- [x] Дашборд-панель (статистика)
- [x] Тёмная и светлая темы
- [x] SVG-иконки статусов (HiDPI)
- [x] Фильтрация по группам
- [x] Контекстное меню (правая кнопка мыши)
- [x] Диалоги добавления/редактирования хоста
- [x] Панель истории узла

### Сервисы
- [x] Уведомления (plyer + встроенный ToastManager для UI)
- [x] Импорт/Экспорт Excel (openpyxl)
- [x] Helpdesk-интеграция (playwright, опционально)

### Инфраструктура
- [x] DI Container (самописный)
- [x] Repository Pattern
- [x] Интерфейсы-абстракции для тестирования
- [x] Набор тестов (pytest, 140 тестов)

## Открытые вопросы / возможные точки роста
- Нет явной системы миграций схемы БД (ALTER TABLE — костыль)
- `StorageManager` (JSON) частично дублирует функционал `DataManager` (SQLite)
- `playwright` — тяжёлая зависимость для helpdesk, возможно заменить на `requests`
