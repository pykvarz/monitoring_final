# Документация по безопасности и соответствию требованиям ИБ

Настоящий документ содержит технические сведения для отделов информационной безопасности (ИБ) и системных администраторов касательно архитектуры безопасности и сетевого взаимодействия приложения **Network Monitor**.

---

## 1. Сетевое взаимодействие и поведение приложения

**Network Monitor** предназначен исключительно для мониторинга доступности конкретно заданных сетевых узлов:
- **Протокол**: ICMP (Internet Control Message Protocol) для IPv4 и IPv6.
- **Тип трафика**: стандартные ICMP Echo Requests / Echo Replies (эквивалентно штатной системной утилите `ping`).
- **Таргетинг**: опрос производится **строго по списку адресов**, внесенных пользователем в конфигурацию. Приложение **не осуществляет** сканирование диапазонов IP-адресов, сканирование портов, поиск уязвимостей или сетевое широковещание (broadcast).
- **Частота**: настраиваемый интервал опроса (по умолчанию 10 секунд). Heartbeat-запись в базу данных троттлится (не чаще одного раза в 60 секунд) для минимизации нагрузки на диск.

## 2. Реализованные защитные механизмы

### 2.1. Защита от Formula Injection / CSV Injection (CWE-1236)
- **Угроза**: Внедрение вредоносных формул в ячейки Excel через имена узлов, адреса или группы для выполнения произвольного кода при открытии файла в MS Excel / LibreOffice Calc.
- **Реализация**: В модуле `excel_service.py` все текстовые поля перед записью в `.xlsx` проверяются на опасные префиксы (`=`, `+`, `-`, `@`, `\t`, `\r`). При обнаружении такого символа ячейка автоматически экранируется ведущим апострофом (`'`), что нейтрализует выполнение формулы в табличном процессоре.

### 2.2. Защита от Command Injection
- **Угроза**: Попытка выполнения произвольных команд ОС через передачу метасимволов командного интерпретатора (`&`, `|`, `;`, `` ` ``, `$()`) в поле IP/хостнейма.
- **Реализация**:
  - Все входные адреса проходят строгую валидацию регулярными выражениями и модулем `ipaddress` (`models.validate_ip_or_hostname`).
  - При запуске внешних утилит (`ping.exe`, сетевые команды контекстного меню) аргументы передаются в `subprocess.run` строго в виде **списка аргументов (argument list)** без использования режима `shell=True`.

### 2.3. Принцип наименьших привилегий (Least Privilege)
- Приложение **не требует прав Администратора** (Local Admin / root).
- При запуске без прав суперпользователя сетевой сервис `PingService` прозрачно переключается на системную утилиту `ping.exe`. Прямые «сырые сокеты» (`ping3` raw socket) используются только при явном наличии соответствующих привилегий у процесса.

### 2.4. Защита от утечек дескрипторов и безопасность базы данных
- Хранилище данных построено на базе SQLite с включенным режимом WAL (`Write-Ahead Logging`), гарантирующим целостность транзакций при внезапных сбоях питания.
- Все обращения к `QSqlQuery` строго изолированы: дескриптор `QSqlDatabase` передается явно в каждый запрос, а освобождение ресурсов `query.finish()` гарантированно вызывается во всех ветках выполнения (включая обработчики исключений).
- Фоновый поток мониторинга `MonitorThread` изолирован и взаимодействует с БД через персональное именованное подключение `monitor_thread_{id}`, исключая конфликты межпоточного доступа.

## 3. Конфиденциальность данных и телеметрия

- **100% локальное хранение**: вся конфигурация (`config.json`), база данных хостов и журнала истории (`hosts.db`), а также лог-файлы (`debug.log`) располагаются исключительно в локальном каталоге приложения.
- **Отсутствие телеметрии**: приложение не содержит встроенных трекеров, сборщиков аналитики, внешних веб-маяков или механизмов удаленной телеметрии.
- **Helpdesk-интеграция**: взаимодействие с корпоративным сервисом заявок (через браузерный движок `playwright`) отключено по умолчанию и активируется только пользователем с указанием внутреннего URL-адреса компании.

---

## 4. Сборка и доверие к бинарным файлам

- Исполняемый файл `NetworkMonitor.exe` собирается локально с помощью открытого компилятора `PyInstaller`.
- Поскольку корпоративный внутренний инструмент поставляется без коммерческого сертификата цифровой подписи (EV Code Signing), модуль Windows SmartScreen может выводить предупреждение о «Неизвестном издателе».
- Исходный код проекта полностью открыт для аудита, статического анализа и независимой локальной сборки скриптом `python build_exe.py`.
