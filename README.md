# Network Monitor

**Network Monitor** — высокопроизводительное десктопное Windows-приложение для мониторинга доступности сетевых узлов и инфраструктуры в реальном времени. Разработано как автономный инструмент системного администратора и инженера технической поддержки.

---

## Ключевые возможности

### ⚡ Параллельный мониторинг и статус-машина
- **Мультипротокольный опрос**: параллельный ICMP-пинг пула узлов с помощью `ThreadPoolExecutor`.
- **Поддержка адресации**: IPv4, IPv6, FQDN, а также однокомпонентные сетевые имена локальной сети (`localhost`, `router`, `dc01`, `nas`).
- **Автоматический выбор движка ping**:
  - *С правами администратора*: высокоскоростные «сырые» сокеты через библиотеку `ping3`.
  - *Обычный пользователь*: прозрачный фоллбэк на системный `ping.exe` без требования прав администратора.
- **Статус-машина**: четкие состояния узла (`ONLINE` → `WAITING` → `OFFLINE` / `MAINTENANCE`) с настраиваемыми порогами таймаутов.
- **Человекочитаемое время простоя**: естественное форматирование («X д Y ч Z мин», «X ч Y мин», «< 1 мин») и точный учет времени падения (`offline_since`).

### 🖥️ Современный UI и дизайн-система
- **Три темы оформления**:
  - **Dark (по умолчанию)**: сбалансированная тёмная тема для снижения нагрузки на зрение.
  - **Tactical (NOC Terminal)**: высококонтрастный режим центра управления сетью с моноширинным шрифтом `Consolas` и неоновыми индикаторами.
  - **Light**: классическая светлая тема.
- **Векторная графика**: строго контурные SVG-иконки в едином стиле Lucide без визуального шума и системных цветных эмодзи.
- **Адаптивная таблица хостов**: автоматическое распределение ширины колонок без черных пустот, деликатная цветовая подсветка строк, сохранение порядка и видимости колонок в конфигурации.
- **Плавающее HUD-окно журнала событий (Always on Top)**: панель событий открепляется в отдельное компактное окно рабочего стола с режимом «Поверх всех окон» и сохранением координат при перезапусках.
- **Desktop Toast-уведомления**: современные плавающие карточки в правом нижнем углу экрана с аппаратной прозрачностью Windows DWM, мягкими тенями и звуковым сигналом.

### 💾 Надёжное хранение данных
- **SQLite (WAL-режим)**: база данных `hosts.db` с версионированными миграциями схемы (`schema_version`), внешними ключами и индексами по статусам и группам.
- **Изоляция потоков**: каждый рабочий поток использует собственное выделенное именованное соединение с БД.
- **Журнал событий**: фиксация каждого изменения состояния узлов с возможностью фильтрации по датам, статусам, группам и поисковым запросам (`Ctrl+H`).
- **Автоматическая ротация**: очистка устаревших записей журнала старше заданного срока (по умолчанию 90 дней).

### 📊 Импорт, экспорт и Helpdesk
- **Массовый импорт и экспорт в Excel (`.xlsx`)**: через библиотеку `openpyxl`.
- **Защита от Formula Injection (CWE-1236)**: автоматическое безопасное экранирование строковых ячеек.
- **Интеграция с Helpdesk**: автоматизированное открытие и закрытие инцидентов через `playwright`.

### ⌨️ Горячие клавиши
- `Ctrl+Space` — пауза / возобновление мониторинга с отображением статуса в панели.
- `Ctrl+H` — открыть общий журнал истории событий.

## Архитектура проекта

Приложение построено по модульным принципам enterprise-архитектуры:
- **DI Container** (`di_container.py`): встроенный инвертор зависимостей (Singleton, Transient, Factory).
- **Repository Pattern** (`core/host_repository.py`): абстракция слоя персистентности над `DataManager`.
- **Thread Safety**: отделение сетевого воркера `MonitorThread` (`QThread`) от графического интерфейса с передачей обновлений через сигналы Qt и подавлением дребезга (debounce 250 мс).
- **Event Bus / Subscribers** (`subscribers/monitor_subscriber.py`): слабая связанность компонентов ядра.

## Установка и запуск

### Требования
- Операционная система: **Windows 10 / 11**
- Python: **3.8+** (протестировано на Python 3.14)

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

*(Опционально для запуска тестов):*
```bash
pip install -r requirements-dev.txt
```

### 2. Запуск приложения
```bash
python main.py
```

### 3. Запуск тестов
Проект покрыт всесторонними unit- и integration-тестами (195 тестов):
```bash
pytest
```
Подробный вывод:
```bash
pytest -v
```

### 4. Сборка автономного .exe
Для сборки переносимого исполняемого файла используется PyInstaller:
```bash
python build_exe.py
```
Готовый дистрибутив `NetworkMonitor.exe` будет сгенерирован в каталоге `dist/`.
